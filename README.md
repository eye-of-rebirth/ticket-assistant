# 工单助手 CLI

面向小团队的学习项目，使用模拟工单数据。当前支持创建、查看、JSON文件保存及DeepSeek模型生成初步排查建议；尚未接入文档查询。

## 首次运行（Windows / PowerShell）

在项目目录中执行：

```powershell
uv sync --locked
```

需要预先安装uv。将.env.example复制为.env，填写自己的DEEPSEEK_API_KEY；不要将真实密钥提交到Git。数据文件不存在时从空列表开始，首次成功创建工单时写入文件：

```powershell
uv run --locked main.py
```

依赖由pyproject.toml和uv.lock管理，包括openai兼容SDK及python-dotenv。已在Python 3.13验证，其他版本尚未核验。上面的命令应在项目目录运行；数据文件和.env按代码文件所在目录定位。PyCharm解释器选择项目.venv。真实模型调用需要有效密钥、可用额度及网络。

## 使用

- 输入普通问题：创建工单（id、text、status），状态为open，先保存到tickets.json，再请求DeepSeek生成分类、摘要和建议。模型结果经解析校验后分别显示，目前不保存到工单。
- 输入“查看”：逐条显示已有工单；没有记录时显示“暂无工单”。查看不创建工单、不写文件。
- 输入“退出”：结束程序。
- 空白输入被拒绝；首尾空白会先移除。“查看”和“退出”是保留命令。
- ID使用已有最大ID加1，空列表从1开始；退出重启后可继续读取和新增。

例如在空工单文件上运行：

```text
请输入问题投影仪无法启动
分类:（模型生成的分类）
摘要:（模型生成的简短摘要）
建议:（模型生成的初步排查建议）
请输入问题查看
{'id': 1, 'text': '投影仪无法启动', 'status': 'open'}
请输入问题退出
再见
```

建议来自模型，仅供初步排查参考。首次请求超时后应用会再尝试一次。连续超时、其他API错误或模型返回格式无效时，程序显示“工单已保存”及相应提示，并继续接受输入。

## 文件与边界

- schema.sql 和 db.py 提供 SQLite 工单表及初始化、写入和按 ID 读取的函数。当前 CLI 的存储入口仍使用 JSON。

- main.py：输入循环、命令分派、启动读取错误提示、创建和保存工单，随后生成建议并处理API失败。
- llm_client.py：加载本地.env；仅在generate_suggestion(text)被调用时读取密钥并创建DeepSeek客户端，缺密钥时抛出明确的ValueError。使用system提示说明输出规则，回答经解析校验后返回字典。导入模块不创建客户端或发送请求；直接运行该文件会执行一次示例调用。
- response_parser.py：先要求输入为字符串，再解析JSON并检查对象结构、三个必需字段和非空字符串值。清洗后的summary最多80个字符（按Python len计算）；不合格时抛出ValueError。
- service.py：create_ticket(tickets, text, status="open")清洗文字、拒绝空白和非法状态、生成ID、将新工单加入传入列表，并返回新工单字典。仅允许open与closed；CLI当前使用默认open，没有切换状态的命令。
- storage.py：load_tickets(path)读取并返回列表，文件不存在时返回空列表，坏JSON仍报错；save_tickets(tickets, path)写入列表。文本读写明确使用UTF-8。
- tickets.example.json：空列表示例；tickets.json是本地运行数据，不提交。
- assessment.py：独立于主入口的筛选练习，不是自动化测试套件。
- tests/test_cli.py：基于标准库unittest的回归检查，由AI辅助编写。
- tests/test_response_parser.py：覆盖响应格式、结构、字段存在性、类型及空白清洗的离线测试，由AI编写。
- tests/test_llm_client.py：使用假密钥和模拟SDK验证延迟初始化、缺密钥恢复、配置参数、返回值和直接运行入口，覆盖缺少摘要、摘要类型错误、超长摘要及超时传播，并检查相关场景下create的调用次数。基础配置由AI编写，新增测试含学习者按参考实现及提示完成的练习。
- .env.example：不含真实密钥的配置示例；.env被Git忽略。
学习进度与技能记录保留在本地docs/，不随当前版本发布。

## 学习与AI辅助说明

这是正在迭代的学习项目。核心CLI与持久化由学习者在提示和局部示例帮助下实现；首次上传整理中的入口封装、数据路径、少量注释修正、文档和回归测试由AI辅助完成，保留学习者原有主体代码与变量命名。项目成果与个人独立能力分开记录，详细学习记录保留在本地。当前版本是CLI源码仓库，尚未部署为网络服务。

## 当前限制

损坏JSON和读取权限不足会提示并结束启动，不自动修复文件；写入失败及并发修改尚未处理。文件保存使用覆盖写入，不具备原子写入保障。尚未校验已有JSON的数据结构。模型字段已校验结构、字符串类型、非空及摘要长度，但不保证建议事实正确，分类尚无枚举限制。提示词已说明摘要最多80字符，解析器仍保留硬校验，不能保证每次回答都遵守规则。缺密钥时CLI仍可启动、查看、退出和保存新工单，生成建议时显示具体失败原因；直接运行llm_client.py的示例入口仍会向外抛出配置或请求异常。尚未提供文档检索或公网部署。
